# Installation

## Requirements

- Unity 2022.3 LTS or later
- IL2CPP and Mono scripting backends are both supported
- Native SQLite binaries are included for Windows (x64 and x86), Linux (x64), and WebGL. Opening a database on a platform outside this list will fail — see [Troubleshooting](troubleshooting.md).

## Import the package

1. Open the Unity Package Manager (**Window > Package Manager**).
2. Select the **Asset Store** tab, or **My Assets** if you've already purchased AyrisDB Free.
3. Find AyrisDB Free and select **Import**.
4. Unity adds the AyrisDB folder to your project's `Assets` folder. No further setup is required.

## Verify it worked

Open **Tools > AyrisDB > Inspector**. If the menu item exists and the window opens, the import succeeded. From here, continue to [Getting Started](getting-started.md).
